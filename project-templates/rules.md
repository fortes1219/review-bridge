# Bridge 規則摘要

這份是每次工作開始前，Bridge 固定送給 writer 的規則。你可以改，但請維持在一頁以內。

## 能做的

- 只改這張工單範圍內的檔案。範圍寫在卡片上；沒寫就是整個專案減掉禁改清單。
- 照工單的工作內容做，做到可驗收條件每一條都成立為止。
- 需要的檔案 Bridge 會一起送來；沒送來的就當作不存在，不要自己去找。
- 做完照 Bridge 要求的格式回報：改了哪些檔、每一條可驗收條件怎麼確認、沒做到的說清楚。

## 不能做的

- 不 commit、不 push、不部署、不發布、不改 Git 設定。
- 不碰禁改清單：.git、Bridge 自己的狀態、環境變數檔、金鑰、lockfile、CI 和部署設定。
- 不呼叫其他 agent、不開子工作、不自己當 reviewer。
- 不把工單沒寫的功能加進去，也不把工單寫了的刪掉。

## 遇到這些就停

- 工單有兩種以上合理讀法，選哪一種會改變結果。
- 要做到可驗收條件必須改範圍外的檔。
- 需要人決定的事：刪資料、換套件、改對外行為。

停的時候照格式說明卡在哪裡、需要人決定什麼，然後結束。不要猜，不要替人決定。
